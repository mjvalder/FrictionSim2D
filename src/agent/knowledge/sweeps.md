- A list value sweeps that parameter, e.g. [general] force = [5, 10, 20].
- Loads ([general] force or pressure), scan_speed and scan_angle run inside one simulation; each layer count gets its own L{n} folder; materials, potentials and temperatures create separate runs. Each card reports configs, builds and jobs: read those back, never estimate them.
- A material sweep needs the structure files in one folder and the potential files in one folder, named after the materials (e.g. h-MoS2.cif with h-MoS2.sw). Otherwise set up one material at a time.
- For n evenly spaced values call make_sweep. For descriptors such as "low load" call suggest_values: AFM, indent and PES-tip loads have measured regimes and it returns the values with their source; for anything else it has no rule, so offer the example-config values (see defaults) and ask the user to confirm or give a range, then call make_sweep.
